# Hut model

`hut.glb` is **Hut** by Quaternius, obtained from
<https://poly.pizza/m/I0IzdnH2iN>.

It is released under CC0 1.0 (public domain). The source model is a compact,
untextured low-poly GLB with two meshes and 404 triangles. It is deliberately
used here as a simple outdoor lighting and shadow test before adding authored
wood and stone materials.
